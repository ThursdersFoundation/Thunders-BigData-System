# backgrounds/ — Full-bleed Backgrounds

1920x1080 WebP backgrounds for the main application surfaces. All backgrounds
are generated by `scripts/generate_webp_assets.py` and share the dark Slate
base (`#0F172A`) with brand accents.

## Files

| File                          | Design                                                        | Intended surface            |
| ----------------------------- | ------------------------------------------------------------- | --------------------------- |
| `dashboard-background.webp`   | Slate gradient, engineering grid, blue corner glow, faint bolt watermark right | Dashboard shell |
| `login-background.webp`       | Deep gradient, centered outlined bolt, soft blue glow, wide grid | Auth / login screens |
| `analytics-background.webp`   | Slate gradient with faint ascending line chart and bar silhouettes | Analytics pages |

## Usage

```css
/* Next.js global or Tailwind arbitrary value */
.dashboard-shell {
  background-image: url("/assets/images/backgrounds/dashboard-background.webp");
  background-size: cover;
  background-position: center;
}
```

```tsx
// Next.js with static import (recommended: hashed URLs + preload)
import loginBg from "@/assets/images/backgrounds/login-background.webp";

<div style={{ backgroundImage: `url(${loginBg.src})` }} />
```

## Guidelines

- Keep text on backgrounds at 4.5:1 contrast minimum; the Slate base supports
  white and `#E2E8F0` text comfortably.
- Do not recolor or brighten the backgrounds; if a lighter variant is needed,
  regenerate via the script with adjusted parameters.
- Each file is 13-48 KB; avoid re-exporting at lower quality than shipped.
