# assets/ — Brand & Static Assets

Complete asset library for the Thunders BigData System: logos, imagery,
icons, self-hosted fonts, and architecture diagrams.

## Brand Colors

| Name         | Hex       | Usage                                                     |
| ------------ | --------- | --------------------------------------------------------- |
| Thunder Blue | `#2563EB` | Primary action color: buttons, links, active nav states    |
| Bolt Yellow  | `#FACC15` | Accent/energy color: logo bolt, highlights, key metrics    |
| Slate        | `#0F172A` | Dark neutral: backgrounds, logo tile, dashboard dark theme |

Accessibility note: Bolt Yellow on Slate passes contrast for large text and
graphics; avoid Bolt Yellow for small body text on light backgrounds.

## Directory Structure

| Path                    | Contents                                                              |
| ----------------------- | --------------------------------------------------------------------- |
| `logo/`                 | Master logo (`logo.svg`) + generated binaries (`logo.png`, `favicon.ico`) |
| `images/`               | Product imagery: logo variants, backgrounds, illustrations, avatars, banners, thumbnails |
| `icons/`                | 38-icon UI set (24px stroke, `currentColor`) + simplified brand icons (64px) |
| `fonts/`                | Self-hosted Inter + Roboto Mono (WOFF2, latin) with OFL license texts  |
| `diagrams/`             | 14 Mermaid diagram sources (`.mmd`) + rendered system architecture (SVG/PNG) |

## Quick Reference

### Logos

- Master: `logo/logo.svg` (source of truth). Variants: `images/logo/`
  (`thunders-logo.svg` horizontal lockup, `-dark`/`-light` background
  variants, `thunders-icon.svg` square mark, `thunders-wordmark.svg`).
- Raster binaries (`logo/logo.png`, `logo/favicon.ico`) are generated via
  scripts and not hand-edited.

### Icons

- UI icons (`icons/navigation`, `icons/data`, `icons/files`, `icons/status`,
  `icons/actions`, `icons/system`) use a 24x24 grid, 2px stroke, and
  `stroke="currentColor"` so they inherit CSS color.
- Brand icons (`icons/brands`) are simplified 64x64 fill marks with fixed
  official colors.

### Fonts

- Inter 400/500/600 for UI text, Roboto Mono 400/500 for code and logs.
- Both under SIL OFL 1.1; license texts in `fonts/licenses/`.
- Load with `next/font/local` -- snippets in `fonts/README.md`.

### Diagrams

- Mermaid sources (`.mmd`) are the editable truth; render with:
  `npx -y @mermaid-js/mermaid-cli -i diagram.mmd -o diagram.svg -b transparent`
- `diagrams/architecture/system-architecture.{svg,png}` ships pre-rendered
  for README embedding.

## Generation & Maintenance

- Binary WebP imagery (backgrounds, banner, thumbnails) is generated by
  `scripts/generate_webp_assets.py` at the repository root; rerun it after
  palette changes.
- SVGs are hand-maintained, XML-valid, emoji-free, and dependency-free.
- Empty directories keep their place in git via `.gitkeep` files where
  content is still pending.
